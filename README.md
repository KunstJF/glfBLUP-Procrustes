# glfBLUP-Procrustes
Scripts for generating results in Kunst et al. (xxxx) A latent factor approach to hyperspectral time series data for multivariate genomic prediction of grain yield in wheat.

# Folder Structure
Within the _scripts_ folder you will find the R scripts used for generating the results and figures found in the paper. The _workflow_ folder has numbered scripts to run the sequence of steps for generating factor scores and performing genomic predictions. The data generated through the scripts in the _workflow_ folder can be visualised using the scripts in the _visualisation_.
